# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in VeloSOVD, please report it
privately through GitHub Private Vulnerability Reporting.

[Report a vulnerability privately](https://github.com/HariKrishnaDukka/VeloSOVD/security/advisories/new)

Please do not report security vulnerabilities through public GitHub issues.

## What to Include

When reporting a vulnerability, please include:

- A clear description of the vulnerability.
- The affected component, file, or version.
- Steps to reproduce the issue.
- The potential security impact.
- Any suggested mitigation, if available.

## Scope

This policy applies to the VeloSOVD repository and its maintained project
components.
